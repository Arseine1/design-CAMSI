# CAMSI ASBL — Aperçu design (statique)

Export statique du design du site CAMSI ASBL, à des fins de présentation/validation.
Aucun backend, aucune base de données — HTML/CSS/JS et images autonomes dans chaque page.

Pages : `index.html` (Accueil), `representation-commerciale.html`, `solutions-numeriques.html`,
`seminaires.html`, `livres.html`, `evenements-immobilier.html`, `contact.html`.

Les formulaires (recherche, contact, newsletter, panier) sont désactivés — cette version
sert uniquement à valider le design visuel.
